# Merge 3.4.2 gym features into 3.4.16 (v4.3) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (native, inline). Steps use checkbox (`- [ ]`) syntax.

**Goal:** Build `Pokemon Arena v4.3.w3x` = the 3.4.16 map plus every 3.4.2 feature it lacks (gym 1-4 easier, `-gym`, busy message, stuck-gym fixes, move-kind check).

**Architecture:** A new module `tools/v3411/gym342.py` with one pure function `patch_script(s: str) -> str` that text-patches the already patched 3.4.16 script (same `rep` style as `apply.py`), plus JASS in `tools/v3411/jass/gym342.j`. `apply.py` calls it at the end of `main()`. No object data changes.

**Tech Stack:** Python 3 (`python -I`), JASS, pjass (`tools/v34/check.py`), pytest.

**Spec:** `docs/superpowers/specs/2026-11-21-merge-3.4.2-into-3.4.16-design.md`

## Global Constraints
- Base: `Pokemon Arena v3.4.10.w3x` through `tools/v3411/apply.py` (= 3.4.16 output). Version file `tools/v3411/version.txt` = `4.3`; build never overwrites a map.
- Gym table (index 0..7 = gyms 1..8, 8 = League): HP x0.35 / 0.45 / 0.70 / 0.85 / 1 / 1 / 1 / 1 / 1; damage and armor x0.45 / 0.55 / 0.75 / 0.85 / 1...; skill-cast chance 0.25 / 0.25 / 0.45 / 0.45 / 0.6...; attack speed x1.7 (`Gym_ASBoost`) only for index 4..8.
- JASS: `code` is a keyword; no 2-letter locals; one function may not call a function defined after it (use `ExecuteFunc` strings); write backslashes with the Write tool.
- Keep every 3.4.16 hook in `Gym_Spawn` / `Gym_Tick` / `Gym_OnDeath` (`Fx_KitStatusX`, `Fx_GymItemX`, `Fx_LeaderHiX`, `Fx_BadgeX`, `Gym_Down`, `Gym_Root`).
- Do not commit or push unless the user asks.

## Review Focus
- A gym challenged by a hero that leaves, dies, or evolves mid-battle must reset or continue, never freeze at "n/6".
- Gym 8 slot (League, index 8) uses the same functions: it must not get the easy-gym table.
- `-gym` with nobody fighting prints "No gym battle right now." and never errors.
- The League arena's `Gym_Spawn(8, ...)` path still works (no dependence on `Gym_ArgG`).
- Missing anchor in a future base script must fail loudly (`ValueError`), not silently skip.

## File Structure
- Create `tools/v3411/gym342.py` (patches), `tools/v3411/jass/gym342.j` (new functions), `tests/test_gym342.py`.
- Modify `tools/v3411/apply.py` (call `gym342.patch_script`), `tools/v3411/version.txt` (`4.3`), `docs/v3.4.11/README.md` (4.3 section).
