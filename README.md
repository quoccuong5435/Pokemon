# Pokemon Arena mod (Warcraft III Reforged)

Python pipeline that turns the Warcraft III map **Pokemon Arena v1.8** (by Dinh Hai Ha) into a modded version
(Mega Evolution, abilities, learned moves, gyms with badges, duels, legends, ...). Nothing is edited by hand in the map editor.

- Map files (`.w3x`) and third-party assets (PKLegends models, Fandom/pokemondb images) are NOT in this repository.
  Put `Pokemon Arena v1.8.w3x` and `PKLegendsv3.2.w3x` in the parent folder to build.
- Build: `python tools/build_v2.py --src "../Pokemon Arena v1.8.w3x" --pkl "../PKLegendsv3.2.w3x" --version X.Y.Z --out "../Pokemon Arena vX.Y.Z.w3x"`
- Tests: `python -m pytest -q` (needs the map files and a pjass binary, see `HANDOFF.md`).
- Balance numbers: `tools/balance.py`. Gameplay code: `tools/jass/mega.j`.
- Patch note page: `analysis/patchnote/index.html` (generated by `analysis/make_patchnote.py`).
