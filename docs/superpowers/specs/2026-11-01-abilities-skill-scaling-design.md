# v2.8 — Pokemon Abilities and skill damage scaling (design)

Requests (user, 2026-11-01): "thêm abi cho pokemon" (list first, then build) and "skill theo hệ số vì chiêu có sát thương
cố định nhưng quái lên level thì không tác dụng"; the user chose the coefficient **by main attribute**.
The list the user reviewed: `docs/pokemon-abilities-proposal.md` (generated by `analysis/ability_list.py`).

## 1. Skill damage scaling
- Applies to every damage event of an enemy target whose damage type is not `DAMAGE_TYPE_NORMAL` (auto attacks excluded) and
  whose source belongs to a user player (player id 0..11): hero skills, trigger damage of the original Arena skills and
  skill dummies. Damage to allies and self damage are not scaled. Damage dealt by Abilities themselves is not scaled.
- multiplier = `min(10, 1 + 0.011 * max(0, mainStat - 50))`; mainStat = highest of Str/Agi/Int (`GetHero*(u, true)`) of the
  source hero; for a non-hero source the best main stat among the owner's heroes (refreshed every second).
- Same rule as the auto attack, which already grows with the main attribute. Level 1 heroes (stat ≤ 50) are unchanged;
  roughly x1.2 at level 10, x2.5 at level 50, x4.4 at level 100 for a 360-stat hero.
- New skills of the 21 Pokemon of v2.3 get the tooltip line "Damage grows with the hero's main attribute."

## 2. Abilities
- One Ability per Pokemon line and one per Mega (Mega replaces the base Ability while Mega Evolved). The nine lines of
  v2.3 keep their skill-4 passive and get no extra Ability.
- A hero shows its Ability as a passive info button at command-card cell `3,1` (free for all 137 forms; Mega uses 0,1 / 1,1).
  It is added/removed by JASS (`Ab_Sync`, every second) when the unit type or the Mega state changes.
- Effects live in the damage event (`Ab_OnDamaging`, replaces the direct registration of `Leg_OnDamage`, which it still calls
  first) and in a 0.5s timer (stun, slow, damage over time) with a 1s beat for heroes (recovery, aura, sync).
- Each Ability has up to two effects; families and numbers are the ones of the proposal file. Deviations from the proposal:
  Synchronize/Cute Charm slow movement only (no attack speed slow); Slow Start = -40% damage dealt for 30s after (re)spawn,
  then +25%; Parental Bond (Mega Kangaskhan) is the existing Kid mechanic; stun uses `PauseUnit`.
- Ability numbers are percentages (or % of max HP) so they keep up with tiered wild creeps.
- "Absorb" abilities compare the attacker's unit name (type text such as "Rock&Ground Pokemon") with a type word, so they only
  react to Pokemon heroes and legends, not to wild creeps.
- Defense (+armor) and Speed (+move speed) are item-bonus abilities `AXA4 AXA6 AXS4 AXS7` added to the hero.

## 3. Not changed
Mega bonuses, wild tiers (5 min), Souls, repick, random, chicken command, shops.
